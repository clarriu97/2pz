# Case presentation

Open `index.html` in any browser. No build, no dependencies, works offline.

- `←` `→` or click — next / previous (stepped slides advance one beat at a time)
- `↑` `↓` — jump a whole slide, skipping the beats
- `N` — speaker notes · `F` — fullscreen · `Home` / `End` — first / last

15 slides, then an 8-slide appendix for Q&A. `Cmd+P` → *Save as PDF* exports one
slide per page with every beat revealed; set the paper size to landscape.
